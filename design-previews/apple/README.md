Отдельный вариант дизайна того же проекта АКМ для согласования. Основная версия сайта находится в `akm-service/dist` и не изменена.

## Как открыть

Изображения можно посмотреть по ссылкам прямо в GitHub без хостинга. HTML-ссылка в GitHub показывает код. Для интерактивного просмотра скачайте репозиторий (Code → Download ZIP), распакуйте и откройте `design-previews/apple/index.html` двойным щелчком. Файлы CSS, JavaScript и папка `assets` должны оставаться рядом с HTML. Для карты Яндекса и внешних ссылок нужен интернет.

Макет содержит работающие меню, выбор услуг, окно записи и FAQ. Он пока не размещён как отдельная веб-страница. Для интерактивной ссылки, доступной с любого устройства, нужна отдельная публикация; она не выполнялась при добавлении этих файлов.

## Оформление

Светлый фон, крупные заголовки, много свободного пространства, полупрозрачная навигация, округлые карточки и оранжевые акценты АКМ. Используются системные шрифты и те же фотографии, что в основном сайте. Логотипы и материалы Apple не используются.

Папка `design-previews` не включена в автопубликацию основного сайта.
