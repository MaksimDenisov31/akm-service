- [Workflow автоматической публикации](.github/workflows/deploy-hostiman.yml)

Готовый основной сайт находится в **akm-service/dist**; сборка и установка зависимостей не требуются. Для локального просмотра откройте **akm-service/dist/index.html** в браузере.

Макет Apple — отдельный вариант дизайна этого же сайта для согласования. Ссылки «посмотреть» открывают изображения прямо на GitHub, дополнительный хостинг для них не нужен. Чтобы проверить кнопки и прокрутку, скачайте репозиторий и откройте **design-previews/apple/index.html** в браузере. GitHub показывает исходный HTML как код; для интерактивного просмотра по общедоступной веб-ссылке макет потребуется разместить отдельно, например в отдельной папке на хостинге. Сам макет пока не опубликован как веб-сайт.

Основной сайт публикуется существующим GitHub Actions workflow. Папка **design-previews** не входит в правила запуска или каталог загрузки этого workflow: добавление макета не заменяет работающий сайт. Пароль FTP передаётся через GitHub Actions Secrets, а не хранится в исходниках. Упоминание `HOSTIMAN_FTP_PASSWORD` в workflow — имя секрета, не его значение.
