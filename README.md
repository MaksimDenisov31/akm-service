# АКМ Сервис

Отдельный репозиторий сайта «Автосервис Корягина и Милешина» в Старом Осколе.

- [Готовые файлы сайта](akm-service/dist)
- [Инструкция проекта и публикация на HostiMan](akm-service/README.md)
- [Workflow автоматической публикации](.github/workflows/deploy-hostiman.yml)

Готовый сайт находится в **akm-service/dist**; сборка и установка зависимостей не требуются. Для локального просмотра откройте **akm-service/dist/index.html** в браузере.

Публикация на хостинг выполняется существующим GitHub Actions workflow. Пароли хранятся в секретах репозитория, а не в исходниках.
