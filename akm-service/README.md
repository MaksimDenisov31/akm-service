# АКМ Сервис

Одностраничный адаптивный сайт «Автосервис Корягин и Милешин» (АКМ) в Старом Осколе. В названии и расшифровке АКМ Корягин всегда указывается первым. Готовые файлы находятся в `dist/`; сборка и зависимости не требуются.

Открыть `dist/index.html` в браузере или разместить содержимое `dist/` на статическом хостинге. Телефоны, ссылка на VK и основной текст находятся в `dist/index.html`, описания интерактивных услуг — в `dist/app.js`.

Фотография мастерской используется как иллюстрация, не является фотографией АКМ Сервис. Источник: Unsplash. Фирменный знак на сайте выполнен типографикой в цветах предоставленного образца.

Адрес: Белгородская область, Старый Оскол, ГСК «Металлург-3». График: ежедневно 08:00–20:00. Координаты: 51.295232, 37.877875. Адрес, график, точка на карте и дополнительные виды работ проверены 14.11.2026 по карточке https://yandex.ru/maps/org/akm_servis/224886767914/ . В `rtext` координаты идут в порядке «широта, долгота», в `ll` и `pt` — «долгота, широта». Исходная точка пользователя: 51.295230, 37.877873; уточнение карточки отличается менее чем на метр.

Прайс не предоставлен. Для записи используются прямые ссылки на телефон и сообщество VK. Форма не собирает персональные данные. В контактах встроен виджет Яндекс Карт; при недоступности виджета адрес, координаты и внешние ссылки на маршрут остаются на странице.

## Публикация на HostiMan

Workflow `.github/workflows/deploy-hostiman.yml` находится в корне репозитория, как требует GitHub Actions. Запускается при изменениях `akm-service/dist`, скриптов публикации или самого workflow в `main`. Ручной запуск: Actions → Deploy AKM to HostiMan → Run workflow.

В Settings → Secrets and variables → Actions добавьте repository secret `HOSTIMAN_FTP_PASSWORD` с FTP-паролем пользователя `s280186`. Не добавляйте пароль в код или Git. Первый запуск без секрета завершится сообщением об отсутствии настройки; после добавления секрета запустите workflow вручную.

Используется FTPS с проверкой сертификата сервера `rufree53.hostiman.ru:21` и шифрованием данных. Назначение — `www/akm-service.h1n.ru` относительно начального FTP-каталога пользователя. Загружаются только файлы `dist`, без удаления файлов на сервере. Файл сначала загружается под временным именем, после проверки размера переименовывается. `index.html` публикуется последним. Удалённые из Git файлы остаются на сервере; удаляйте их отдельно через ISPmanager при необходимости. Публикация всех файлов не является одной атомарной операцией.

Локальная проверка без подключения: `python -B scripts/deploy_hostiman.py --check`. Тесты: `python -B -m unittest discover -s scripts -p "test_*.py"`.

FTP-публикация не заменяет вход в кабинет HostiMan раз в 30 дней и не включает HTTPS для посетителей сайта.
